# 常用命令速查

日常操作用的命令集合。项目背景/安装说明见根目录 `README.md`，这里只列命令。
统一约定：在项目根目录 `PythonProject1\` 下执行，用项目自带的 venv：

```powershell
.\.venv\Scripts\python.exe main.py <子命令>
```

如果 `python`/`python.exe` 已经指向这个 venv，直接写 `python main.py ...` 也一样。

## 1. 首次使用

```powershell
# 打开 Edge 登录雪球（弹滑块就手动拖一下），登录后回终端按回车。
# 登录态存在 data/edge_profile，之后基本不用再登。
python main.py login
```

## 2. 雪球帖子抓取

```powershell
# 抓 .env 里 XUEQIU_USERS 配置的所有大V的新帖（增量，已入库的帖子不会重复抓）
python main.py crawl

# 只抓某个时间段——一旦带了 --since/--until，会放开翻页上限一直翻到日期以外为止，
# 这是给新加的大V回补历史帖子用的（不带参数默认只翻最近 MAX_PAGES 页，抓不到太久以前的）
python main.py crawl --since 2020-01-01
python main.py crawl --since 2026-06-01 --until 2026-06-30

# 看库里抓到了哪些人、多少条、时间范围
python main.py stats
```

## 3. AI 总结

```powershell
# 日/周/月/年总结，不带 --date 默认今天/本周/本月/今年
python main.py summary daily
python main.py summary daily   --date 2026-06-29
python main.py summary weekly
python main.py summary monthly --date 2026-06-15
python main.py summary yearly  --date 2026-01-01

# 只处理某一个大V（传 user_id 或昵称片段），默认处理全部大V
python main.py summary weekly --user 大V昵称

# 忽略缓存，强制重新生成
python main.py summary daily --regen

# 精华帖（按互动量取前 N 条），--period 可选 week/month/year，默认 month
python main.py highlights --period month --topn 10
```

总结分层归并（省token）：周/月复用日总结，年复用月总结。所以新大V要先把日总结跑一遍，
再往上跑周/月/年，否则上层总结会因为没有下层缓存而效果差。

## 4. A股行情/财务数据同步（选股功能依赖）

```powershell
# 行情快照：同步全市场最新价格/涨跌幅/市盈率等（建议收盘后跑，每天跑一次）
python main.py stock-sync

# 历史K线回补：均线类预设策略（金叉/多头排列）依赖，只需首次跑一次
# 会弹出一个可见Edge窗口逐个股票同源fetch，约1小时跑完5000+只，跑完自动关
python main.py stock-backfill --days 365 --delay 0.5

# 财务指标同步：基本面预设策略依赖，新一期财报披露后重新跑一次
python main.py stock-sync-finance

# 板块成分股全量同步：个股详情页「所属板块」反查完整覆盖依赖，只需首次跑一次
# （前提是已经在网页上做过一次"板块名单同步"，见下方）
python main.py stock-sync-sector-members
```

> **板块名单同步（`sector_catalog` 表本身）没有对应的CLI命令**，只能在网页看板
> "选股 → 数据同步" 面板里点"板块名单同步"按钮触发（对应 `/api/stock/sync-sectors`）。

## 5. 启动网页看板

```powershell
# 默认 127.0.0.1:5000
python main.py serve

# 自定义端口/监听地址（注意：直接跑 python web.py 不支持 --port，必须走 main.py serve）
python main.py serve --host 127.0.0.1 --port 5050
```

打开 `.env` 里配置的用户对应端口的网页即可，例如 `http://127.0.0.1:5000`。

## 6. 定时自动采集（Windows 任务计划程序）

```powershell
# 注册每日任务（默认22:37，可用 -At 改时间；无需管理员）
powershell -ExecutionPolicy Bypass -File register_task.ps1
powershell -ExecutionPolicy Bypass -File register_task.ps1 -At 21:07

# 立即试跑一次 / 查看状态 / 删除任务
Start-ScheduledTask -TaskName XueqiuDailyCrawl
Get-ScheduledTask   -TaskName XueqiuDailyCrawl | Get-ScheduledTaskInfo
Unregister-ScheduledTask -TaskName XueqiuDailyCrawl -Confirm:$false
```

任务要设成**仅在登录 Windows 时运行**（采集要弹有头Edge，需要桌面）。每次运行输出在
`data/schedule.log`。

## 7. 排障常用

```powershell
# 装/更新依赖
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 检查端口是不是已经被别的进程占了（Windows允许多进程同时监听同一端口，
# 遇到"改了代码但网页没反应"先查这个，确认只有一个PID在监听）
Get-NetTCPConnection -LocalPort 5000 -State Listen
Get-Process -Id <上面查到的PID> | Select-Object Id, ProcessName, StartTime

# 测试带中文的POST接口：不要用 curl -d（git-bash下中文JSON body可能被破坏，
# Flask端 request.get_json 会静默拿到 None），改用 Python requests
.\.venv\Scripts\python.exe -c "import requests; print(requests.post('http://127.0.0.1:5000/api/summary/ask', json={'user':'用户ID','type':'daily','key':'2026-07-07','question':'一句话概括'}).json())"
```

## 8. 网页看板里能做、命令行没有对应命令的操作

以下功能目前只在网页上（没有CLI子命令），登录 `python main.py serve` 后在对应页面操作：

- 选股页「数据同步」面板：板块名单同步（见上方第4节说明）
- 选股页「筛选条件」：数值条件筛选 + 名称/代码/拼音缩写模糊搜索 + 板块筛选 + 预设策略组合
- 选股页「股票分组」：自选股分组管理
- AI总结页：选中一份总结后，底部"向AI提问"框可基于该总结内容追问细节
