# 云服务器部署手册

> 适用分支：`feature/cloud-deploy`
> 架构：Linux 云服务器跑 Docker 栈（7服务）+ 本机 Windows 跑 browser worker

---

## 一、服务器选型

| 项目 | 推荐 |
|------|------|
| 系统 | Ubuntu 22.04 LTS |
| 配置 | 2核4G起步（选股CPU密集，2G内存有OOM风险） |
| 磁盘 | 系统盘20G + 数据盘50G（挂载到 `/data`） |
| 安全组 | 开放 80、443；其余端口（5433/6432/6380/8088/8090）绑定 127.0.0.1，不对外暴露 |

---

## 二、服务器初始化

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# 安装 Nginx + Certbot
sudo apt install -y nginx certbot python3-certbot-nginx

# 挂载数据盘（假设设备名 /dev/vdb，按实际调整）
sudo mkfs.ext4 /dev/vdb
sudo mkdir -p /data
echo '/dev/vdb /data ext4 defaults 0 2' | sudo tee -a /etc/fstab
sudo mount -a
```

## 四、配置 .env

在 `backend/` 目录创建 `.env`：

```bash
cat > /data/app/backend/.env << 'EOF'
# ===== 数据库 =====
POSTGRES_USER=natapp
POSTGRES_PASSWORD=换成强随机密码
POSTGRES_DB=natapp

# ===== Redis =====
# docker-compose 内部网络，不需要改
# REDIS_URL 由 compose 注入

# ===== 安全 =====
JWT_SECRET=换成随机64位字符串

# ===== AI中转站 =====
RELAY_API_KEY=你的key
RELAY_API_URL=https://www.micuapi.ai/v1
RELAY_MODEL=gpt-5.4-mini
RELAY_API_IMAGE_KEY=你的图像key（可选）

# ===== 浏览器 Worker（服务器用 Chromium） =====
BROWSER_CHANNEL=
HEADLESS=true
DATA_DIR=/data/app/backend/data

# ===== 管理员引导（首次启动自动创建） =====
ADMIN_USERNAME=admin
ADMIN_PASSWORD=换成强密码

# ===== 其他 =====
CORS_ORIGINS=["https://你的域名"]
EOF
```

> `BROWSER_CHANNEL=` 留空，服务器走 Chromium；本机 `.env` 保持 `BROWSER_CHANNEL=msedge`。

## 五、调整 docker-compose 端口绑定

服务器上不需要把端口暴露到公网，修改 `docker-compose.yml` 把 api/postgres/redis 绑定到本地：

```yaml
# postgres
ports:
  - "127.0.0.1:5433:5432"

# redis
ports:
  - "127.0.0.1:6380:6379"

# api
ports:
  - "127.0.0.1:8088:8000"

# frontend（由 Nginx 反代，也可绑本地）
ports:
  - "127.0.0.1:8090:80"
```

## 六、启动 Docker 栈

```bash
cd /data/app/backend

# 首次构建并启动
docker compose up -d --build

# 查看状态
docker compose ps

# 执行数据库 migration
docker compose exec api alembic upgrade head

# 查看 api 日志确认启动正常
docker compose logs -f api
```

## 七、数据迁移（从本机迁移现有数据）

在**本机**执行：

```bash
# 导出本机数据库（本机 postgres 端口 5433）
pg_dump -h localhost -p 5433 -U natapp natapp > natapp_backup.sql

# 上传到服务器
scp natapp_backup.sql root@服务器IP:/data/
```

在**服务器**执行：

```bash
# 导入数据
docker compose exec -T postgres psql -U natapp natapp < /data/natapp_backup.sql
```

## 八、配置 Nginx 反代 + HTTPS

```bash
# 创建 Nginx 配置
sudo tee /etc/nginx/sites-available/natapp << 'EOF'
server {
    listen 80;
    server_name 你的域名;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name 你的域名;

    # certbot 会自动填充这两行
    # ssl_certificate ...
    # ssl_certificate_key ...

    client_max_body_size 10m;

    # 前端静态 + 反代
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # API（前端容器内 Nginx 已做 /api 反代，此处兜底直连也可）
    location /api {
        proxy_pass http://127.0.0.1:8088;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
EOF

sudo ln -s /etc/nginx/sites-available/natapp /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 申请 HTTPS 证书
sudo certbot --nginx -d 你的域名
```

## 九、服务器 Browser Worker（可选，替代本机）

如果希望抓取任务也在服务器上跑，需要额外配置 Chromium 登录态：

```bash
# 安装 Playwright + Chromium
cd /data/app/backend
pip install playwright
playwright install chromium
playwright install-deps chromium

# 第一次登录雪球（需要 VNC 或图形界面，headless=false）
# 临时改 .env：HEADLESS=false，然后手动跑一次抓取触发登录窗口
# 登录成功后改回 HEADLESS=true

# 启动 browser worker
celery -A app.workers.celery_app worker -Q browser --pool=solo --loglevel=info
```

> 无图形界面的服务器需要先安装 `xvfb`：
> ```bash
> sudo apt install -y xvfb
> Xvfb :99 -screen 0 1280x720x24 &
> export DISPLAY=:99
> ```

## 十、本机 Windows Browser Worker 连云端 Redis

如果保持本机跑 browser worker，只需让本机连服务器 Redis：

1. 服务器安全组临时开放 6380 端口（或用 SSH 隧道更安全）
2. 本机 `.env` 改：
   ```
   CELERY_BROKER_URL=redis://服务器IP:6380/0
   CELERY_RESULT_BACKEND=redis://服务器IP:6380/0
   ```
3. 启动：
   ```bash
   celery -A app.workers.celery_app worker -Q browser --pool=solo
   ```

**推荐用 SSH 隧道代替直接开端口：**
```bash
ssh -L 6380:127.0.0.1:6380 root@服务器IP
# 本机 .env 仍用 redis://localhost:6380/0
```

## 十一、PostgreSQL 内存优化（2C4G 服务器）

```bash
docker compose exec postgres psql -U natapp -c "
  ALTER SYSTEM SET shared_buffers = '256MB';
  ALTER SYSTEM SET work_mem = '8MB';
  ALTER SYSTEM SET maintenance_work_mem = '64MB';
  SELECT pg_reload_conf();
"
```

## 十二、常用运维命令

```bash
# 查看所有服务状态
docker compose ps

# 重启某个服务
docker compose restart api

# 查看实时日志
docker compose logs -f worker

# 执行 migration
docker compose exec api alembic upgrade head

# 备份数据库
docker compose exec postgres pg_dump -U natapp natapp > backup_$(date +%Y%m%d).sql

# 更新代码并重新部署
git pull
docker compose up -d --build api worker beat frontend
```
