  ## 二、当前发现的问题

  ### 1. 日线卖出信号与组合持仓状态可能不一致

  现象：

  - 个股日线界面已经出现卖出信号倒三角；
  - 组合策略实际执行交易表中，对应股票仍显示「持有中」。

  需要重点检查：

  - 个股日线卖出信号和组合回测使用的信号计算是否完全一致；
  - 组合回测是否只在特定条件下执行卖出；
  - 卖出信号日期是否被正确加入 signals_by_date；
  - 组合持仓的卖出逻辑是否因为筛选条件、日期范围或数据缺失而跳过；
  - 持仓明细中的 sell_date 和 status 是否使用了同一套判断。

  优先统一「日线信号」和「组合回测卖出信号」的计算口径。

  ### 2. 需要支持剔除 ST 股票

  目前已有创业板、科创板排除条件，但尚未支持：

  - ST
  - *ST

  建议在后端候选新开仓筛选阶段，根据股票名称过滤：

  - 名称包含 ST；
  - 名称包含 *ST；
  - 必要时兼容名称前后的空格和特殊字符。

  已有持仓仍应允许正常卖出，不能因为后续名称筛选条件而阻止清仓。

  建议新增参数：

  exclude_st: bool

  前端增加「排除 ST」选项，默认建议开启。

  ### 4. 返回按钮是通用性问题

  多个界面的「返回」按钮无法返回上一个页面。

  建议检查并统一：

  - 所有页面返回按钮是否使用了固定路由；
  - 是否应改为 navigate(-1)；
  - 没有历史记录时再回退到默认页面；
  - 统一封装一个返回组件或返回函数，避免每个页面重复实现。

  建议逻辑：

  const navigate = useNavigate();

  const goBack = () => {
    if (window.history.length > 1) {
      navigate(-1);
    } else {
      navigate("/");
    }
  };

  需要排查的页面至少包括：

  - StockDetail.tsx
  - 其他带「返回」按钮的详情页和复盘页。
